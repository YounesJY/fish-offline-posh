# Theme attribution

The files in this directory are the official Oh My Posh themes, vendored so
that `chooseOhMyPosh` works without network access.

- Project: https://github.com/JanDeDobbeleer/oh-my-posh
- Theme source: https://github.com/JanDeDobbeleer/oh-my-posh/tree/main/themes
- Snapshot: Oh My Posh v33.4.0, 125 themes (2026-11-24)
- License: MIT (see the Oh My Posh repository)

To refresh the snapshot:

```bash
git clone --depth 1 https://github.com/JanDeDobbeleer/oh-my-posh.git /tmp/omp
cp /tmp/omp/themes/*.omp.* themes/
```
